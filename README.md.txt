# 🎯 Guess It! - 2-Player Number Guessing Game

A fun offline 2-player game where each player sets a secret number and takes turns guessing the opponent's number. First to guess correctly wins!

## 🎮 How to Play

1. **Enter Player Names** - Customize player names
2. **Set Secret Numbers** - Each player secretly enters a number (1-100 or custom range)
3. **Take Turns Guessing** - Players alternate guessing the opponent's number
4. **Get Hints** - Too High ⬆️ or Too Low ⬇️ after each guess
5. **Win!** - First to guess the opponent's number wins 🏆

## ✨ Features

- 🎯 2-Player Offline Gameplay
- 🔒 Secret Number Entry (Password Hidden)
- 🎨 Dark/Light Theme Toggle
- 🔊 Sound Effects with Volume Control
- 📊 Difficulty Levels: Easy, Medium, Hard
- 🏆 Score Tracking
- 📜 Guess History
- 📱 PWA Ready - Install as Native App

## 📱 Install as App

### Android
1. Open the game in Chrome
2. Tap the install prompt or menu → "Install app"
3. Play like a native app!

### iOS
1. Open in Safari
2. Tap Share button → "Add to Home Screen"
3. Play from home screen
